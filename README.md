# CooCowork

Owner: `src/definition.ts`

给 Coopanion 的 Cortico World 扩展:Coo 在你干活时陪着。它知道你什么时候坐下、什么时候走开、日历上接下来是什么,能陪你开专注时段,第二天还记得前一天在忙什么。只支持 Windows。

## Coo 会在什么时候开口

| 时机 | 例子 |
|---|---|
| 每天第一次坐下 | 带上前一天的概要和今天的日程 |
| 日程开始前 10 分钟 | 「十分钟后站会」 |
| 离开 20 分钟以上回来 | 午饭回来 |
| 连续在电脑前满 90 分钟 | 专注时段里和日程进行中不打扰 |
| 专注时段里停在你说好要避开的网站上满 2 分钟 | 每段只提一次 |
| 专注时段结束 | 这段时间在电脑前多久、在哪些程序上 |

收到这些事件后说不说、说什么由 Coo 决定。时长都可以在设置里修改;「主动程度」选「少打扰」时,只有日程、专注时段和每天第一次见面会马上告诉 Coo。安静时段里只有日程提醒会马上告诉 Coo。

## 对 Coo 说

- 「我要写周报,一个小时,别让我刷 B 站」:开一个专注时段。
- 「今天我都干了啥」「昨天上午在忙什么」:按天回顾。
- 「明天有什么会」:看日历。
- 「以后每天六点提醒我复盘」:Coo 用自己的唤醒器。
- 「把今天的记录删掉」「把记录都删了」:删除活动记录。

## 安装与设置

1. 设置窗口切到高级模式,在「扩展」页安装 `cortico-world-coocowork`(或按路径安装本目录),重启进程后在「World 总览」启用 CooCowork。
2. 在 CooCowork 页的「常用设置」接入日历:粘贴订阅地址(Google 日历的「iCal 格式的私密地址」、Outlook 发布的 ICS 链接、iCloud 公开日历的 webcal:// 链接),页面当场读一遍、列出接下来几项日程,确认后保存;或者选择一个本机 `.ics` 文件。订阅地址只存在部署目录的 `.env`(`COWORK_CALENDAR_URL`),页面上只显示打码后的样子。
3. 同一页还有主动程度、连续在电脑前提醒、安静时段、不记录标题的程序(可从今天用过的程序里一键添加)、记录保留天数和删除记录。改动当场生效。其余数值(采样间隔、离开判定等)在「配置」页。

## 记录了什么、存在哪

- 每 5 秒读一次前台窗口的程序名、窗口标题和距上次键鼠操作的时长。不截图,不记录按键内容。
- 按天写在本扩展的数据目录 `days/YYYY-MM-DD.jsonl`,默认保留 14 天;World 页的数据页签可以一键清除。
- 无痕/隐私窗口、密码管理器和聊天程序(微信、QQ、Telegram、WhatsApp、Signal)只记程序名,不记标题;名单在配置里修改。关掉「记录窗口标题」后只记程序名。
- Coo 读到的事件和回执会随模型请求发给你配置的模型服务。

## 开发

```bash
corepack pnpm install
```

```bash
pnpm typecheck && pnpm test
```

`tests/e2e.test.ts` 经真 Cortico Core 跑一个模拟工作日(Coo 由脚本扮演);设 `COWORK_TRANSCRIPT=docs/e2e-transcript.md` 时把这一天写成记录。需求与设计在 `docs/`。

| 文件 | 内容 |
|---|---|
| `src/definition.ts` | World 定义、工具与事件的自描述 |
| `src/world.ts` | 事件、工具、日程提醒、WebUI 声明 |
| `src/activity.ts` | 采样折成离开、回来、连续在电脑前、专注时段 |
| `src/probe.ts` | Windows 前台窗口与空闲时长 |
| `src/calendar.ts` | .ics 解析与重复规则展开 |
| `src/daylog.ts` | 按天的活动记录 |
| `src/model-text.ts`、`src/ENV_PROMPT*.md` | Coo 读的文字,中英两份 |
